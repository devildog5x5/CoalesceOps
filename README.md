# Coalesce Ops

One practice for joining separate teams, systems, and sites into a single operation.

Open `index.html` locally, or unzip the zip into Hostinger `public_html`.

**Hostinger zip:** [CoalesceOps-1.0.7.zip](https://github.com/devildog5x5/CoalesceOps/releases/download/v1.0.7/CoalesceOps-1.0.7.zip) — unzip into `public_html`. Rebuild with `powershell -File .\build_site_zip.ps1` (filename includes the version from `VERSION`). Footer on every page: Coalesce Ops v1.0.7.
