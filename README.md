# Coalesce Ops

One practice for joining separate teams, systems, and sites into a single operation.

**Sites:** [coalesceops.com](https://coalesceops.com), [coalesceops.pro](https://coalesceops.pro), and [coalesceops.org](https://coalesceops.org) serve this same website. Open `index.html` locally, or deploy the zip into Hostinger `public_html`.

**Hostinger zip:** [CoalesceOps-1.0.3.zip](https://github.com/devildog5x5/CoalesceOps/releases/download/v1.0.3/CoalesceOps-1.0.3.zip) — unzip into `public_html` on each domain. Rebuild with `powershell -File .\build_site_zip.ps1` (filename includes the version from `VERSION`). Footer on every page: Coalesce Ops v1.0.3.
