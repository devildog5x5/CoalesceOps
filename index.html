Where the work splits

An operation can look unified on an organization chart and still run as several. A handoff has no owner. Two systems disagree about the same job. A second site invented its own week.

Leadership then hears a different account than the people doing the work. Coalesce Ops comes on site, watches how the work actually moves, and writes what must join for the operation to run as one.
